# Map quality audit – 2026-11-12 (P1.2.10)

kula-critic ran `kula map`, `brief`, `clusters` and `explain` on five public repos of different shapes and checked each claim against the source. Every finding below is fixed, with a regression test, or accepted with a reason.

## Repos

| Repo | Shape | Worst finding |
|---|---|---|
| shadcn-ui/taxonomy 298a885 | TS / Next.js, 188 files | Root `package.json` emptied the map; 8 route nodes gave 0 entry points |
| encode/httpx b5addb6 | Python, 125 files | Largest cluster named after a test file; `str.splitlines` bound into `tests/` made a false `httpx → tests` cycle |
| BurntSushi/ripgrep 178cc02 | Rust workspace, 226 files | `crates/core` (the `rg` binary) missing; `mod util;` resolved into another crate's `tests/util.rs` |
| benbjohnson/wtf 05bc90c | Go service, 94 files | `ctx.Value` bound to `sqlite.NullTime.Value`; 22 gorilla `r.HandleFunc` routes, 0 found |
| pydantic/pydantic-core 383eb95 | Rust + Python, 270 files | Three manifests in the root gave three empty `.` packages |

## Mis-clustering, one per repo

- taxonomy: cluster `components/ui · utils` was 25 dependency nodes plus files, 7 functions. Labels now count code symbols only.
- httpx: `httpx · test_timeouts` (276 members, 5 from the test). Labels skip test paths and take the majority file.
- ripgrep: `core/flags · powershell` (961 of 979 members in `flags/defs.rs`). The majority stem now wins, ties alphabetical.
- wtf: `sqlite · dial` held 372 of 396 symbols, partly through the false `Value` edge. That edge is gone; see Accepted for the rest.
- pydantic-core: `tests/validators · Model` mixed tests, library Python and Rust. Test paths no longer name a cluster.

## Fixed

1. A manifest at the repo root emptied the map. The root package now owns every dir no deeper manifest claims (`tree.rs`, longest prefix).
2. Several manifests in one dir gave several packages. One package per dir, ranked Cargo, pyproject, go.mod, package.json.
3. Cluster labels: code symbols only, no test paths, majority dir and stem with an alphabetical tie-break, unique suffixes for repeats. Labels live in `src/graph/communities.rs`.
4. One naming scheme: `explain`, `clusters` and `brief` all use the stored label.
5. `explain <file>` found no cluster. It now goes by the node's community; `explain <dir>` merges the submodules under it.
6. Entry points: every `HANDLES` route target is an `http` entry; `http_name` covers Go and drops the bare `get_` prefix; `[project.scripts]`, `[tool.poetry.scripts]` and Cargo `[[bin]]` are read (`src/map/manifests.rs`); `build.rs main` is `build`, not `cli`; Rust `#[test]` and `#[tokio::test]` are found; the file lookup is a map, not a scan per entry.
7. Dirs with no manifest (ripgrep `crates/core`) show under a synthetic root package.
8. `brief` caps tests at 5 and API items at 10 and says how many it left out, so cycles and god modules stay on the page.
9. False edges:
   - Rust `mod`/`use` lookups stay in the caller's crate (path up to `src`, `tests`, `benches` or `examples`) unless anchored; other crates' `tests/` are never a target.
   - A guessed CALLS edge never lands in a test file from non-test code (httpx `splitlines`).
   - A Go method on an unknown receiver only guesses within its own package (wtf `ctx.Value`).
   - Go routes: any router's `.HandleFunc(` / `.Handle(`, with gorilla `.Methods("X")` as the method.
10. Module names were all `src`. They are now the dir relative to the package, minus `src` segments (`a`, `crates/core`).

Tests: `tests/map_layout.rs` (6 tests; the Rust import and guessed-call tests were checked to fail before their fixes) and `scans_go` in `src/layers/routes_tests.rs`. Bench unchanged: precision 0.97, recall 1.00, `resolved` 59/59.

## Accepted

- Env vars cluster with the config file that names them (taxonomy `next.config.mjs`) when that file is the densest reader. Label propagation follows edges; a layer view is P1.2 follow-up work, not a bug.
- wtf's domain, http and sqlite packages still share one large community after the false edge fix. Splitting by package boundary is a design choice for `docs/design/map.md`.
- No Python to Rust edges for PyO3 (pydantic-core). Cross-language binding is out of scope until SCIP ingest (P1.1.8).
- `export const authOptions` (taxonomy) is not a symbol: TS top-level consts are not indexed yet.
- `check architecture` reports intra-crate Rust module cycles. They are real cycles, so the check is right to report them; a warn level for intra-crate cycles is follow-up work.
- Fan-in mixes CALLS and IMPORTS, and markdown prints package paths, not names. Minor; left as is.
