# Tables layer audit – 2026-11-12 (P1.3.8)

kula-critic read `src/layers/tables.rs` after P1.3.5 landed. Every finding below is fixed; the regression cases live in the unit tests of `src/layers/tables.rs` and `src/layers/tables/scan.rs`, and in `tables_link_models_to_handlers_for_impact` (`tests/layers.rs`).

## Fixed

- Model names matched in any file. A use now needs the model's file, an import of the model, or an import of its module, in the same language. Prisma's client alias counts only after `prisma.` or `db.`.
- Raw SQL keywords matched in code and comments (`Array.from(items)`, `d.update(orders)`, `# delete from x`). They now count only when the keyword and the name share one string literal. `table` left the keyword list; `public.invoices` resolves to `invoices`.
- Models were keyed by name alone, so two `User` classes collided. They are keyed by file and name. Django `abstract = True` and SQLAlchemy `__abstract__` no longer make tables.
- Python class headers that span lines are joined.
- Table names are case folded everywhere (`query`, `impact`, the KG), so Prisma `User` meets SQL `user`.
- `.prisma` files are found by extension, since no language pack claims them.
- New forms: `@@map(name: "x")`, Drizzle `pgSchema(..).table("x")`, `pgTableCreator` templates, Django `app/models/<file>.py` packages.
- SQL: comments are blanked first; `CREATE OR REPLACE|TEMP|TEMPORARY|UNLOGGED|GLOBAL|LOCAL TABLE` across any whitespace; quoted names with spaces; the last dotted part wins.
- `impact table:X` rates uses `inferred` and declarations `resolved`, so `--min-confidence resolved` keeps only the models and migrations.
- The owner of a byte comes from a sorted, parent-linked def index; lines come from newline offsets.
- A migration's edge always starts at its file, as the docs say. Docs now say Prisma's `mapsTable` starts at the schema file.
- `table:NAME` that matches no table is an error, not a fuzzy symbol search.
- Texts are not held between passes; the second pass re-reads code files only when tables exist.

## Accepted limits

- Uses are read from text, not types: `session.query(User)` links, a model passed through a variable of another name does not.
- `impact --down` from a table is empty; tables have no callees.
